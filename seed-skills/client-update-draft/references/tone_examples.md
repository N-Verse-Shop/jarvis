# Tone Examples — Nexus Studio voice

Three pairs. Bad on left, good on right. Use the right-hand pattern.

## Done-bullets

| ❌ Bad                                          | ✅ Good                                                                   |
|------------------------------------------------|--------------------------------------------------------------------------|
| Started working on the checkout                 | Checkout flow merged to `main`. Test URL: ibons.staging.../checkout      |
| Did some refactoring on the API                 | Reduced cart API p95 from 320 ms → 95 ms. PR #182                       |
| Discussed design with the team                  | Design system v2 reviewed; 14 components ready, 3 deferred to v2.1      |

Pattern: **artefact + measurable change + link**. No verb without an object.

## Up-next bullets

| ❌ Bad                          | ✅ Good                                                                |
|---------------------------------|----------------------------------------------------------------------|
| Continue working on payments    | Wire Stripe live keys + first prod transaction by Wed                |
| Improve performance             | Lighthouse score from 78 → 95 by Friday review                       |
| Plan the next sprint            | Backlog grooming Tue 10:00; you'll get sprint plan Wed evening       |

Pattern: **verb + outcome + date-boxed**. Vague "continue" never appears.

## Questions

| ❌ Bad                          | ✅ Good                                                                |
|---------------------------------|----------------------------------------------------------------------|
| Any feedback so far?            | The shipping rules need a yes/no on free-over-€50 by Thursday        |
| Thoughts on the design?         | The hero variant A vs B — your call by Friday so we can prep launch  |
| Let me know what you think      | Approve the Stripe live keys now, or after board on Tuesday?         |

Pattern: **concrete decision the client owns + deadline + binary or short-list choice**.
